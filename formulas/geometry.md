# Analytic Geometry Formulas

## 2D Coordinate Geometry

### Distance Between Two Points
```
d(A,B) = √( (x₂-x₁)² + (y₂-y₁)² )
```

### Midpoint
```
M = ( (x₁+x₂)/2 ,  (y₁+y₂)/2 )
```

### Section Formula (point dividing AB in ratio m:n)
```
P = ( (m·x₂ + n·x₁)/(m+n) ,  (m·y₂ + n·y₁)/(m+n) )
```

## Lines in 2D

### General form
```
ax + by + c = 0
```

### Slope-intercept form
```
y = mx + b
m = slope,  b = y-intercept
```

### Slope from two points
```
m = (y₂ - y₁) / (x₂ - x₁)
```

### Point-slope form
```
y - y₁ = m(x - x₁)
```

### Distance from point (x₀,y₀) to line ax+by+c=0
```
d = |a·x₀ + b·y₀ + c| / √(a² + b²)
```

### Parallel lines: same slope (m₁ = m₂)
### Perpendicular lines: m₁ · m₂ = -1

---

## Planes in 3D

### General equation
```
ax + by + cz + d = 0
```
Normal vector: **n** = (a, b, c)

### Plane through point P₀ with normal **n**
```
n · (r - r₀) = 0
a(x-x₀) + b(y-y₀) + c(z-z₀) = 0
```

### Distance from point (x₀,y₀,z₀) to plane ax+by+cz+d=0
```
d = |a·x₀ + b·y₀ + c·z₀ + d| / √(a² + b² + c²)
```

## Areas & Volumes

### Triangle
```
Area = ½ · base · height
Area = ½ · |a × b|           (vector formula)
Area = √[s(s-a)(s-b)(s-c)]   (Heron's formula, s=(a+b+c)/2)
```

### Circle
```
Area      = π · r²
Perimeter = 2 · π · r
```

### Sphere
```
Volume      = (4/3) · π · r³
Surface area = 4 · π · r²
```

### Cylinder
```
Volume       = π · r² · h
Surface area = 2·π·r·h + 2·π·r²
```

### Cone
```
Volume       = (1/3) · π · r² · h
Slant height = √(r² + h²)
Surface area = π·r·(r + slant height)
```

## Conic Sections

### Circle centered at (h,k)
```
(x-h)² + (y-k)² = r²
```

### Ellipse (a > b)
```
(x-h)²/a² + (y-k)²/b² = 1
```

### Parabola (vertical)
```
y - k = a(x-h)²    (a>0: opens up, a<0: opens down)
```
